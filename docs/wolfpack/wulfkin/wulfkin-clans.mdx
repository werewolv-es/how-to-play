# The Wulfkin

The Wulfkin are a Wolfpack sub-faction that activates when all main Wolfpack killers are eliminated — they step up as the pack's killers, sharing the Wolfpack win condition.

:::warning[Not Yet Documented]
This faction has not yet been documented in the official How To Play guide. For more information, please refer to the [Unofficial H2P Wiki](https://unofficialhowtoplay.co.uk/index.php/Wulfkin_Clans). Note: the unofficial wiki may contain inaccurate or outdated content.
:::

## Roles

- [Wulfkin Assassin](/roles/WulfkinAssassin) — poisons a target each night, killing them on a subsequent night
- [Wulfkin Seer](/roles/WulfkinSeer) — checks a target for Wolfpack alignment or wolf blood each night
- [Wulfkin Scout](/roles/WulfkinScout) — follows a target each night to see who visits them
